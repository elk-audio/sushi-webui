# sushi-webui

Responsive web control surface for the [Sushi](https://github.com/elk-audio/sushi) plugin host.

Status: **specification phase**. Nothing here is implemented yet.

- `docs/ARCHITECTURE.md`: technical architecture (Go backend, Svelte frontend, WebSocket protocol, meters, deployment on Elk Audio OS)
- `docs/UX_DESIGN.md`: UX design (Mixer → Track → Plugin, layouts for desktop, tablet and phone, widget specs)
- `mockups/index.html`: clickable UX sketch with a simulated engine; open it in a browser
